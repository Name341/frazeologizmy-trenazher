# Тренажёр по фразеологизмам

Интерактивный тренажёр для различения устойчивых выражений и обычных словосочетаний. В него включены 285 выражений из учебного списка и примеры обычных словосочетаний из литературных произведений.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## GitHub Pages

В настройках репозитория выберите **Pages → Build and deployment → Deploy from a branch**, затем ветку `main` и папку `/ (root)`. Сохраните настройки и дождитесь публикации.
